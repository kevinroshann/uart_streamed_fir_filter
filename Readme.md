UART STREAMED FIR FILTER

basically this project contains mainly 2 parts. 
The fir filter which is a low pass 2khz filter created in verilog.
The second part is the uart section. which is of baud rate 115200. 
The project is sucessfully implemented on icebreaker fpga its clock rate is 12mhz.

To view the reports go to /resources folder there you can see the reports of each section

To view the complete code go to the /verilog/final_code/ 

To view individual section code and replicate it go to /verilog section.
